# Kill PID

```blogEnginePageDate
29 июля 2026
```

Иногда при работе в нескольких IDE приложение не может запуститься, потому что кто-то занял порт. Как найти и убить
процесс который занимает порт? 

Для этого сначала найдем приложене по порту - в Windows CMD, например для порта 3000:

```
netstat -ano | findstr :3000
```

В последнем столбце будет `PID`:

```
TCP    0.0.0.0:3000    0.0.0.0:0    LISTENING    12345
```

Убить процесс:

```
taskkill /PID 12345 /F
```
